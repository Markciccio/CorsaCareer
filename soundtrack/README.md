# CorsaCareer · colonna sonora

Questa cartella contiene i brani forniti dall’autore della carriera e copiati
localmente dalla cartella Download. I file non vengono riprodotti
automaticamente all’avvio: il loro uso deve essere controllabile dal giocatore.

## Mappa narrativa suggerita

| Atmosfera | Brani consigliati |
|---|---|
| Alba, primo capitolo, speranza | `Morning Horizon`, `Faint Horizon`, `Neon Horizon` |
| Concentrazione e preparazione | `Circuit Focus`, `Paddock Wire`, `Static Between Lines` |
| Griglia e tensione | `Gridline Rush`, `Gridline Groove`, `Checkered Skyway` |
| Sponsor, mercato, trattative | `The First Pitch`, `Post-Race Analysis` |
| Vittoria e consacrazione | `Proud Momentum`, `The Final Lap` |
| Crisi, sconfitta, ripartenza | `Faded Checkered Flag` |

I nomi sono indicativi: il prossimo passaggio sarà aggiungere un lettore con
play/pausa, volume, stop e selezione automatica per capitolo, test, gara,
podio, crisi e ritiro.
